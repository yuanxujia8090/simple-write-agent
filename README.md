# simple-write-agent

本地运行的公众号长文写作 Agent：从话题或 `.txt`/`.md` 素材开始，经过研究、论点、大纲、草稿和审查，导出 Markdown 主稿与同源 HTML。

当前处于开发准备，功能实现任务待执行。协作顺序为：**先实现、阶段留证、完成后学习**；本人答题和课程完成度不作为开发前置条件。
