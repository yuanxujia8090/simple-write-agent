# 0005：拒绝产物最小回退到父阶段

- 状态：accepted
- 日期：2026-09-04

PRD 3.7 原表述"由用户选择回到 `drafting` 或 `outline`"在拒绝大纲时语义矛盾（大纲未确认前无 drafting 可回退），且把流程依赖决策推给用户。决策：拒绝采用最小回退，回退到产生被拒产物的阶段：论点→`thesis`、大纲→`outline`、事实核查报告→`research`、终稿→`drafting`；保留已确认上下文，保存用户原始反馈和结构化修订指令，并把修订指令作为下一轮该阶段的输入约束。

## 考虑过的方案

- 让用户自由选择回退深度：用户不了解阶段依赖，可能重走已确认流程或丢失上下文。
- 一律回到 `drafting`：大纲与事实核查报告未确认时回退到 drafting 无意义。

## 影响

LangGraph 拒绝边的目标确定化；修订指令需要持久化并注入下一轮节点；确认门禁交互需向用户展示回退目标。
