# 0007：MVP 行为边界与质量门

- 状态：accepted
- 日期：2026-09-04

MVP 进入实现前补全一批此前未定义的行为边界，全部为 MVP 范围内、避免实现时靠猜的决策。核心：Checkpoint 以阶段为原子单位；质量判断采用"结构门槛 + 交给人"；素材边界（`--file` 可重复、单文件 ≤ 1MB、UTF-8 容忍 BOM）；slug 保留中文；SearchProvider 接入 Tavily（mock 可验收）；单进程 + `session.db` 锁检测；快速模式待验证素材自动进入降级改写清单。

## 已确认决策

1. **Checkpoint 粒度**：阶段为原子单位。每阶段完成写一个稳定 checkpoint；阶段执行中中断则重做整个阶段，不做节点内中断。恢复逻辑因此简化，与 PRD 4.4"不把半成品当作完成成果"一致。
2. **质量判断**：Agent 质量判断 = 结构门槛（最低完成条件）+ 规则层（事实/证据）；内容质量由人工确认门禁把关，不引入模型内容自评。`maxRounds` 默认 2，仅兜底流程错误（结构不达标重试）。
3. **素材边界**：`--file` 可重复指定；单个素材文件 ≤ 1MB；编码 UTF-8（容忍 BOM）；超限/编码错误给可读提示不崩溃。
4. **slug 规则**：`--slug` 用户指定优先；默认从标题安全化——保留中文，清理 `/ \ : * ? " < > |`，空格转 `-`；文件冲突时 `slug-2`/`slug-3` 不覆盖既有文件。
5. **SearchProvider**：定义可插拔接口并接入 Tavily（凭据从配置读取）；mock 可验收，配置凭据后可用真实搜索；不因未配凭据阻塞 MVP 验收。
6. **运行边界**：单进程 + 单活动会话；检测到 `session.db` 被其他进程占用时提示"另一实例正在运行"并退出，不处理多进程并发写入。
7. **快速模式素材**：自动采纳的素材标记"待验证"，其对应外部硬事实自动进入终稿确认时的降级改写清单（原因代码 = 未验证素材）。

## 默认采纳项（与需求一致，无独立方案）

- 会话命名 = `主题前 8 字 + 日期`；`/list` 最近事件 = 最近 Trace 类型 + 简述；
- 默认主题 = 内置默认色值，字段结构对齐 `archive/my-theme.json`；
- HTML 支持 mdast 子集（标题/段落/引用/代码/列表/表格/图片/强调/链接/分隔线），其余保留原文并警告；
- 无 `config.json` 首次启动引导填写 provider/baseURL/model；
- 模型、文件、配置错误给可读提示和可恢复路径。

## 影响

各决策分别落到 PRD（2.3/3.3/3.6.2/4.4/4.5/4.6/5.1/5.2/5.3）、计划（T2/T3/T5/T8/T9/T10/T12/T13/T14/V4）与 CONTEXT 术语表；实现时按此边界编码，不扩大范围。
