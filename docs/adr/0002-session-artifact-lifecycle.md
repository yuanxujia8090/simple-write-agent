# 0002：写作产出版本与流程检查点分离

- 状态：accepted
- 日期：2026-09-02

写作 Agent 将 Checkpoint（检查点，可恢复的流程状态）与 ArtifactVersion（产出版本，某个阶段生成的内容）分开建模。Checkpoint 负责恢复当前流程，ArtifactVersion 负责保留每个阶段的 `draft`、`rejected` 和 `temporary` 成果。用户拒绝成果时不删除历史版本；同一阶段重新执行时只替换最近的临时成果。这样可以处理误操作、中断和重做，而不会把半成品误当成已完成成果。

## 考虑过的方案

- 把所有成果直接嵌入 checkpoint：难以独立保留被拒成果，也会让流程状态与内容生命周期耦合。
- 只保存当前成果：用户拒绝或重做后无法恢复之前的内容。

## 影响

会话恢复需要同时读取流程检查点和当前产出版本。用户界面默认只展示当前成果；被拒成果和临时成果用于恢复与审计，不进入普通会话列表。
