## 阶段方案必须写什么

1. 目标：这一阶段结束后用户能多做一件什么事。
2. 范围：包含、不包含、已知简化边界。
3. 数据流：输入从哪来、写到哪、谁负责校验。
4. 关键规则：失败时如何回退，哪些状态不能被静默改写。
5. 验证方法：可复现命令和预期结果。
6. 实际结果：真实改动、测试通过数量、实测输出、与方案的偏差、未验证项。

阶段方案在开工前写，`## 实际结果` 在收尾时补；不能用计划内容冒充已完成内容。
