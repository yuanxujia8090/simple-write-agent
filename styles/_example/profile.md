# 示例风格包（无私人语气）

把本文件复制到 `~/.writing-agent/styles/<你的-id>/profile.md` 后按需改写。

## 用途

给写作 Agent 一段可注入的约束摘要。这里只放**通用骨架**，不含任何真人声线、私人事例或完整风格指南正文。

## 建议填写

1. **读者与场景**：一句话说明写给谁、用在什么场合。
2. **语气**：短句 / 口语程度 / 是否第一人称（写原则，不写私人故事）。
3. **禁止**：空话、未核实的「亲测」、把内部黑话当默认用语等。
4. **真源（可选）**：若完整指南在本机其他路径，只写「请另读：<绝对路径>」，不要把全文粘进本包后再提交到 git。

## 入口约定

- 包目录内优先使用 `profile.md`；若无此文件，实现方可回退读取 `SKILL.md`。
- 可选同级文件：`banned-words.txt`、`samples/`（示例，非必须）。
